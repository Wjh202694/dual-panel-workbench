双区域滚动示意图

上下两个区域各自独立滚动，中间分割线可自由拖动。

  1. 拖动中间分割线，自由调整上下高度比（默认黄金分割 φ）。
  2. 拖动上方面板右侧滑块，内部小长方形（卡片）依次向下滚动。
  3. 下滑面板右侧滑块独立控制下方区域内容。
  4. 滑块支持鼠标拖拽、滚轮与触摸板。
  5. 右上角数字为该面板的滚动百分比。
初始面积比例 φ = 1.618
上方面板 flex-grow = 1.618，下方面板 = 1，两面板等宽，因此高度比即面积比。
拖动分割线后比例实时变化，双击可复位回 φ。
