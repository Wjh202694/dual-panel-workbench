# 双面板 · 共识文档工作台

> 上面是对话，下面是共识文档，中间一条能拖的中缝。
> 应用只做两件事：**把对话导成「决策 + recap」卡片**，**把共识文档原地编辑并写回原文件**。

![界面](docs/screenshot.png)

一个 Electron 桌面应用，给"人和 agent 一起干活"用的：

- **你写的决策，一字不动地被记下来** —— 导入一段对话日志，每轮变成上方一张卡片，
  左边是你当时的原话和 agent 给你的选项，右边是这一轮 agent 干了什么的提炼摘要。
- **共识文档只有一份，写回原路径** —— 下方所见即所得编辑 `.md` / `.txt`，
  存盘就是写回你导入的那个文件。应用不给 agent 开任何 API，
  所以 agent 用自己的 Read 工具读到的永远是最新内容；应用另外监听文件变化，
  agent 在外面改完能自动重载。

## 跑起来

```bash
cd app
npm install     # 首次
npm start       # 构建渲染层 + 启动应用
```

国内网络下 Electron 没装上的话：

```bash
cd app
ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/ npx install-electron
```

自检（会真的开窗口、用临时目录、不联网）：

```bash
cd app && npm test
```

## 三分钟上手

1. 点右上角 **导入对话** → 弹出一份**有名字的清单**（标题 / 项目路径 / 多久之前），
   不需要去文件框里认 UUID 文件名。选一段对话 → 上方出现轮次卡片。
2. 每张卡片的 **recap** 由提炼引擎生成。右上角 **模型** 按键可以随时切换模型
   （默认走 opencode 的免费模型）。引擎跑挂了也能在菜单「工具 → 提炼缺失的 recap」里补。
3. 点右上角 **导入文档** → 同样是一份清单（「最近导入」+ 项目文件夹里的 `.md` / `.txt`）。
   选中后下方直接编辑，改动自动写回原文件。

## 界面约束

界面是按手绘草图定的，所以加东西之前先想清楚：

- **两个面板本身**跟 Demo 一致：上方是 8 张空白卡片（导入对话后被对话卡片替换），
  右侧两条独立滚动条，中缝可拖，默认黄金分割 φ = 1.618
- **下方不出现任何"这是哪个文档"的信息** —— 没有标签栏、工具栏、路径状态栏、保存状态胶囊
- 顶栏：左边「导入对话 / 导入文档」两个按钮，右上角一个「模型」切换按键

引擎设置、模型清单这些都放在**独立小窗口**里，主界面不脏。

## 已知限制

- 一次只显示一个文档，导入新的就替换旧的。
- 相对路径的 Markdown 图片不显示（要给主进程加图片代理）。
- 只认 Claude Code 那种 JSONL 对话日志。
- 导入对话并提炼会把日志内容发给提炼引擎（默认是 opencode 的免费模型）。
  介意的话在「工具 → 自定义模型与命令」里换成本地脚本。
- 未做打包（`electron-builder`），目前只能 `npm start` 跑源码。
